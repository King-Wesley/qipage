# 栖页 Qipage

一个简洁的个人网址导航页。把喜欢的网站放在眼前，给日常留一点空白。

## 功能

- 实时时钟、日期和中文问候语。
- 必应、百度和 Google 搜索切换。
- 常用、工作、灵感、生活四组网址，支持添加、编辑和删除。
- 三张本地壁纸，也可上传自己的照片并调整遮罩。
- 页面文字统一为白色，壁纸不再自动改变文字颜色。
- 四种时钟组件：极简数字、卡片数字、上下排版、指针表盘。
- 时钟字体、大小、秒数、12/24 小时制与手动颜色设置。
- 玻璃/纯色面板、可配置点缀色、专注模式，以及手机布局。
- 名字、收藏和偏好保存在当前浏览器中。

## 本地运行

先安装 [Node.js](https://nodejs.org/)，然后在项目目录运行：

```sh
npm start
```

无需安装第三方依赖。启动后，在 Chrome 打开：

```text
http://127.0.0.1:4173/
```

Windows 用户也可以双击 **启动栖页.cmd**；启动器会使用 PATH 中的 Node.js，启动本地服务并尝试打开 Chrome。若未找到 Chrome，请手动输入上面的地址。

`npm start` 启动的服务可用 `Ctrl+C` 停止；Windows 启动器开启的服务会在后台继续运行，电脑重启后需再次启动。本地服务只监听本机。

## 文件结构

```text
index.html       页面结构
style.css        页面样式
app.js           搜索、网址管理与风格设置
style-config.js  设置迁移、校验与时钟计算
assets/          三张本地壁纸
server.cjs       无依赖的本地静态服务器
launch.cjs       Windows 启动器
启动栖页.cmd     Windows 双击入口
```

## 数据与使用

网页主体及背景图均在本地加载。搜索和访问收藏的网站仍需要网络。

收藏及个人设置不会写入仓库，而是保存在浏览器的 `localStorage` 中。不同浏览器、用户配置以及不同地址各自保存数据；请固定使用 `http://127.0.0.1:4173/`。清除网站数据也会清除这些设置。

这份源码也可由普通静态网站服务托管；`server.cjs` 仅用于本地访问。

## 风格配置预览

主分支已包含确认后的时钟与风格配置。点击右上角设置按钮，在「时钟风格」选择组件，在「颜色与细节」修改字体、大小、颜色、秒数和小时制，在「面板外观」选择玻璃或纯色。设置即时生效并保存在原来的浏览器数据中，已有姓名、收藏和壁纸保持不变。

普通界面文字固定为白色；时钟默认白色，可手动选择颜色。点缀色用于选中背景、边框和面板，不会根据壁纸变化。可点击「还原时钟与配色」恢复风格默认值，该操作不清空收藏。

开发测试先运行 `npm ci` 安装测试依赖，再运行 `npm test` 验证旧设置迁移、输入校验、12/24 小时制、指针角度和设置持久化。开发预览可通过 `PORT` 指定其他本机端口，例如 PowerShell 中 `$env:PORT=4174; npm start`。

下载此分支的 ZIP 并解压后，可以直接双击 `index.html` 预览风格；日常使用也可按前述方法运行本地服务。浏览器按访问地址分别保存数据，因此文件预览和原本本机服务地址的数据不会自动互通。

## 切换分支与本地页面

浏览器加载的 `app.js` 已包含时钟配置代码，切换到此分支后，旧版栖页服务也能读取新的界面，不需要额外放开服务文件访问范围。修改 `ui.js` 或 `style-config.js` 后运行 `npm run build` 生成浏览器文件；生成的 `app.js` 一并提交。测试会检查它与源文件保持一致。涉及后台服务的分支切换仍需重启 Node 服务。
