# 栖页 Qipage

一个简洁的个人网址导航页。把喜欢的网站放在眼前，给日常留一点空白。

## 功能

- 实时时钟、日期和中文问候语。
- 必应、百度和 Google 搜索切换。
- 常用、工作、灵感、生活四组网址，支持添加、编辑和删除。
- 三张本地壁纸，也可上传自己的照片并调整遮罩。
- 根据文字所在区域的背景明暗，自动切换黑白文字。
- 深浅色面板、专注模式，以及手机布局。
- 名字、收藏和偏好保存在当前浏览器中。

## 本地运行

先安装 [Node.js](https://nodejs.org/)，然后在项目目录运行：

```sh
npm start
```

无需安装第三方依赖。启动后，在 Chrome 打开：

```text
http://127.0.0.1:4173/
```

Windows 用户也可以双击 **启动栖页.cmd**；启动器会使用 PATH 中的 Node.js，启动本地服务并尝试打开 Chrome。若未找到 Chrome，请手动输入上面的地址。

`npm start` 启动的服务可用 `Ctrl+C` 停止；Windows 启动器开启的服务会在后台继续运行，电脑重启后需再次启动。本地服务只监听本机。

## 文件结构

```text
index.html       页面结构
style.css        页面样式
app.js           搜索、网址管理与背景自动配色
assets/          三张本地壁纸
server.cjs       无依赖的本地静态服务器
launch.cjs       Windows 启动器
启动栖页.cmd     Windows 双击入口
```

## 数据与使用

网页主体及背景图均在本地加载。搜索和访问收藏的网站仍需要网络。

收藏及个人设置不会写入仓库，而是保存在浏览器的 `localStorage` 中。不同浏览器、用户配置以及不同地址各自保存数据；请固定使用 `http://127.0.0.1:4173/`。清除网站数据也会清除这些设置。

这份源码也可由普通静态网站服务托管；`server.cjs` 仅用于本地访问。
