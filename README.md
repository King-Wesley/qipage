# 栖页 Qipage

个人网址导航，包含实时钟表、搜索、收藏分组、背景自动黑白配色，以及 DeepSeek 每日精选。

此功能开发在 `feature/daily-deepseek` 分支，尚未合并到 `main`。

## 本地运行

安装 [Node.js](https://nodejs.org/) 18 或更新版本，在项目目录运行：

```sh
npm start
```

不需要安装第三方依赖。在 Chrome 打开 **http://127.0.0.1:4173/**。Windows 也可以双击「启动栖页.cmd」。更新程序后需要重新启动本地服务，刷新网页本身不会升级正在运行的服务。

## 直接在网页配置 DeepSeek

点击右上角「每日内容」图标，或新闻栏的设置按钮：

1. 粘贴自己的 DeepSeek API Key，选择模型。
2. 填写关注的新闻领域，例如「人工智能、机器人、国内要闻」，最多三个方向。
3. 选择每天 3、5 或 8 条新闻，填写喜欢的壁纸风格。
4. 选择每天的更新时间（北京时间，默认 08:00），开启自动更新。
5. 点击「保存并测试连接」，然后在新闻栏点击「现在更新」生成第一份内容。

密钥仅由本机 Node 服务保存于 `.private/config.json`。网页不会回显已保存的密钥，也不会把它存进浏览器 localStorage。`.private/` 整个目录已排除在 Git 之外，请勿手动上传它。新闻与壁纸缓存也保存在这个目录。

API 请求会使用你自己的 DeepSeek 账户额度。没有配置 Key 时，程序不会发起收费的模型或搜索请求。模型默认使用 `deepseek-flash`，也可选择 `deepseek-v4-pro`。

## 每日新闻如何产生

- 使用 [DeepSeek 官方 Search API](https://api-docs.deepseek.com/guides/search/) 按你填写的领域检索。
- 严格按北京时间筛选当天已发布的结果；无发布时间、旧闻和未来时间不纳入。
- 将候选标题、来源、发布时间与资料交给 DeepSeek，按影响、可靠性和关注领域筛选、合并重复事件。
- 网页显示中文摘要、入选理由、来源、发布时间及原文链接。原文链接与时间始终来自搜索候选，模型不能自行编造。
- 当天符合条件的新闻不够时，不拿旧新闻凑数。来源时间依赖检索结果，本栏是个人阅读辅助，重要事实可点原文核实。

## 每日壁纸如何产生

从近期 Bing 每日图片中读取候选及摄影描述，由 DeepSeek 按偏好挑选一张。当前实现按图片描述挑选，不生成图片。所选图片下载到本机，保留来源和版权说明；自适应文字配色继续生效。可在背景设置中随时切回内置图片或自己的照片。

## 自动更新时间与失败处理

本地服务运行时，每分钟检查北京时间是否到达设定时间。同一天已成功生成的内容会复用缓存；电脑关闭时不会运行，重新启动后会补上错过的当日更新。

手动更新可重新生成，有短暂冷却。网络、额度或上游接口失败时保留上次成功内容，明确显示其日期与更新失败状态。尚未连接或无今日结果时展示真实空状态，不使用演示新闻冒充今日精选。

## 开发与测试

```sh
npm test
```

测试使用模拟网络响应，覆盖日期筛选、候选校验、缓存、并发、错误保留、密钥不回显和本地接口限制，不消耗真实 API 额度。

主要文件：`index.html` / `style.css` / `app.js` 为导航页；`daily.js` / `daily.css` 为每日内容与配置面板；`daily-service.cjs` 为检索、筛选、缓存与调度；`server.cjs` 为本地 HTTP 服务。

此版本需要运行 Node 后端，不能只上传前端到 GitHub Pages 后直接调用带密钥的接口。云端版本需要另外部署相同后端并配置访问权限。
