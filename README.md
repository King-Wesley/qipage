# 栖页 Qipage

个人网址导航，包含实时钟表、搜索、收藏分组、固定白色文字与可配置时钟，以及 DeepSeek 每日精选。

“今日，值得一看”使用统一白色文字，面板材质与点缀色跟随风格设置。

main、feature/daily-deepseek 和 feature/android-apk 同步提供每日内容与外观设置。

[查看更新日志](CHANGELOG.md)

每日配文包括页顶短句、时钟下方文字和页脚句子，由 DeepSeek 按北京时间每天生成并缓存。失败时保留上次配文及真实日期；没有配置密钥时使用默认文字。新闻支持 14–24 px 字号，在外观设置或新闻区 A− / A＋ 调整并自动保存。

## Windows：下载、解压、双击即用

1. [下载当前功能分支 ZIP](https://github.com/King-Wesley/qipage/archive/refs/heads/feature/daily-deepseek.zip)；私人仓库需先登录 GitHub。将完整 ZIP 解压到你准备长期保留的文件夹。
2. 双击「启动栖页.cmd」。脚本会准备运行环境并启动本地服务，优先打开 Chrome，没有 Chrome 时打开 Windows 默认浏览器。
3. 网页右上角「每日内容」里填入自己的 API Key、关注领域和壁纸偏好，保存并测试，再点击「现在更新」。不填 Key 也可以使用时钟、搜索、收藏与内置壁纸。

不用手动安装 Node.js，不用运行 npm install。支持 Windows 10/11 的 x64 与 ARM64 系统；使用 Windows 自带 PowerShell。第一次准备环境需联网，之后本地导航可离线使用，新闻与每日壁纸更新仍需网络。

统一入口 qipage.cmd 会检查可用的 Node.js 22 或更新版本；如果没有，会从 [Node.js 官网](https://nodejs.org/en/blog/release/v24.22.1) 下载固定版本 24.22.1 的便携 ZIP，核对仓库中固定的 SHA-256 后才使用，保留官方许可证。便携环境放在项目的 .runtime/，不会安装到系统或修改全局 PATH，也无需管理员权限。首次下载失败时，检查官网连接后再次双击即可。

运行后可在浏览器访问 [本机栖页](http://127.0.0.1:4173/)。请先完整解压，不要在 ZIP 预览窗口内直接双击。

### 可选：登录 Windows 后自动启动

- 双击「启用开机自启.cmd」：为当前账户添加启动项，以后登录 Windows 后在后台启动服务，不自动弹出浏览器。
- 双击「关闭开机自启.cmd」：移除启动项，当前已经运行的服务不受影响。

不需要在每台电脑上手工找启动文件夹。启动项仅在你主动启用后写入；下载或运行网页不会自行修改开机启动设置。公司电脑的管理策略可能禁止自启；失败会提示原因，手动启动仍可使用。

请保留解压后的项目文件夹。移动文件夹或更换运行环境后，重新运行一次启用脚本。Windows 的启动应用设置中也可以查看 Qipage 启动项。电脑关机或尚未登录时不会运行。

### 已安装 Node.js 的开发者 / 其他系统

Node.js 22 或更新版本可直接运行 npm start，再手动打开本机网址。项目不依赖第三方包。Windows 命令入口也支持 qipage.cmd background，只启动后台服务。更新程序后需要重新启动本地服务，刷新网页本身不会升级正在运行的服务。

## 直接在网页配置 DeepSeek

点击右上角「每日内容」图标，或新闻栏的设置按钮：

1. 粘贴自己的 DeepSeek API Key，选择模型。
2. 填写关注的新闻领域，例如「人工智能、机器人、国内要闻」，最多三个方向。
3. 选择每天 3、5 或 8 条新闻，填写喜欢的壁纸风格。
4. 选择每天的更新时间（北京时间，默认 08:00），开启自动更新。
5. 点击「保存并测试连接」，然后在新闻栏点击「现在更新」生成第一份内容。

密钥仅由本机 Node 服务保存于 `.private/config.json`。网页不会回显已保存的密钥，也不会把它存进浏览器 localStorage。`.private/` 整个目录已排除在 Git 之外，请勿手动上传它。新闻与壁纸缓存也保存在这个目录。

API 请求会使用你自己的 DeepSeek 账户额度。没有配置 Key 时，程序不会发起收费的模型或搜索请求。模型默认使用 `deepseek-flash`，也可选择 `deepseek-v4-pro`。

## 每日新闻如何产生

- 使用 [DeepSeek 官方 Search API](https://api-docs.deepseek.com/guides/search/) 按你填写的领域检索。
- 严格按北京时间筛选当天已发布的结果；无发布时间、旧闻和未来时间不纳入。
- 将候选标题、来源、发布时间与资料交给 DeepSeek，按影响、可靠性和关注领域筛选、合并重复事件。
- 网页显示中文摘要、入选理由、来源、发布时间及原文链接。原文链接与时间始终来自搜索候选，模型不能自行编造。
- 当天符合条件的新闻不够时，不拿旧新闻凑数。来源时间依赖检索结果，本栏是个人阅读辅助，重要事实可点原文核实。

## 每日壁纸如何产生

从近期 Bing 每日图片中读取候选及摄影描述，由 DeepSeek 按偏好挑选一张。当前实现按图片描述挑选，不生成图片。所选图片下载到本机，保留来源和版权说明；自适应文字配色继续生效。可在背景设置中随时切回内置图片或自己的照片。

## 自动更新时间与失败处理

本地服务运行时，每分钟检查北京时间是否到达设定时间。同一天已成功生成的内容会复用缓存；电脑关闭时不会运行，重新启动后会补上错过的当日更新。

手动更新可重新生成，有短暂冷却。网络、额度或上游接口失败时保留上次成功内容，明确显示其日期与更新失败状态。尚未连接或无今日结果时展示真实空状态，不使用演示新闻冒充今日精选。

## 开发与测试

```sh
npm test
```

测试使用模拟网络响应，覆盖日期筛选、候选校验、缓存、并发、错误保留、密钥不回显和本地接口限制，不消耗真实 API 额度。

主要文件：`index.html` / `style.css` / `app.js` 为导航页；`daily.js` / `daily.css` 为每日内容与配置面板；`daily-service.cjs` 为检索、筛选、缓存与调度；`server.cjs` 为本地 HTTP 服务。

此版本需要运行 Node 后端，不能只上传前端到 GitHub Pages 后直接调用带密钥的接口。云端版本需要另外部署相同后端并配置访问权限。

## 时钟与风格设置

此分支已合入 main 中确认的风格功能，保留完整 DeepSeek 每日精选。右上角设置内可选择极简数字、卡片数字、上下排版、指针表盘，调整字体、大小、秒数、12/24 小时制、时钟颜色、点缀色和玻璃/纯色面板。普通文字固定白色，只有时钟颜色由你手动选择。已有收藏、背景与 API 配置继续保留。

运行前端开发检查：先 npm ci，再 npm test。修改 ui.js 或 style-config.js 后运行 npm run build，生成并一并提交 app.js。
